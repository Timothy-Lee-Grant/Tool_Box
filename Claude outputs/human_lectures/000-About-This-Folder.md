# human_lectures/ — what this folder is for

**Audience: Timothy.** Every document here is written for him to read and learn from.

## Purpose
Lectures that teach Timothy the concepts behind Tool_Box and behind how he works with AI, so that he understands his own project well enough to explain it, extend it, and defend it in interviews (target: software engineer at Microsoft).

## How documents here are written
- **Teaching first.** Start from first principles, explain *why* before *how*, and build each idea on the previous one.
- **Grounded in this repo.** Use Tool_Box's real files, real PRs/issues and real incidents as examples, and quote short snippets with their paths.
- **Visual.** Mermaid diagrams (GitHub renders them) and tables wherever structure matters. Show before/after when something changed.
- **Plain language.** Define every term the first time it appears. No unexplained jargon.
- **Active learning.** End with exercises and self-check questions (answers in `<details>` blocks).
- **Honest.** Say where something is uncertain or unverified.

## Naming
`NNN-Title.md`, three-digit sequence in creation order. The first line is a timestamp: `YYYY_MM_DD_HH_MM-(Title)`.

## Not for this folder
Dense, exhaustive technical dumps intended to brief another AI system. Those go in `../detailed_descriptions/`.
